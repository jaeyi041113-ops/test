## 01.

```
개념 이름: 양적 변수
개념 설명: 양적 변수는 숫자로 나타낼 수 있으며, 값의 크기나 차이에 의미가 있는 변수이다. 양적 변수는 다시 셀 수 있는 값으로 이루어진 이산형 변수와, 일정한 범위 안에서 연속적인 값을 가질 수 있는 연속형 변수로 구분할 수 있다. 예를 들어 팀 인원 수는 이산형 변수이고, 키나 과제 소요 시간은 연속형 변수에 해당한다.
데이터 분석에서 중요한 이유: 변수의 유형에 따라 사용할 수 있는 요약 방법과 시각화 방법이 달라지기 때문이다. 양적 변수는 평균이나 중앙값 등의 대표값을 계산할 수 있고, 히스토그램을 이용해 데이터가 어느 구간에 많이 분포하는지도 확인할 수 있다. 따라서 분석을 시작하기 전에 변수가 어떤 유형인지 판단하는 것이 중요하다.
```


## 02.

```
개념 이름: 히스토그램
개념 설명: 히스토그램은 데이터를 일정한 구간으로 나눈 뒤, 각 구간에 포함된 데이터의 개수를 막대로 나타낸 그래프이다. 특히 연속형 양적 변수의 전체적인 분포 형태를 확인하는 데 유용하다. 같은 데이터라도 구간의 폭을 어떻게 정하느냐에 따라 그래프의 모양이 달라질 수 있다.
데이터 분석에서 중요한 이유: 평균과 같은 하나의 숫자만으로는 데이터가 실제로 어떻게 분포되어 있는지 알기 어렵다. 히스토그램을 함께 보면 값이 특정 구간에 몰려 있는지, 좌우로 치우쳐 있는지, 극단적인 값이 존재하는지 등을 확인할 수 있다. 또한 구간의 설정에 따라 그래프의 인상이 달라질 수 있으므로, 시각화 결과를 해석할 때 구간폭도 함께 확인해야 한다.
```


## 03.

```
개념 이름: 중앙값
개념 설명: 중앙값은 데이터를 크기순으로 정렬했을 때 가운데에 위치하는 값이다. 데이터의 개수가 홀수라면 정가운데 값을 사용하고, 짝수라면 가운데 두 값의 평균을 중앙값으로 사용한다.
데이터 분석에서 중요한 이유: 평균은 모든 값을 이용하기 때문에 극단적으로 크거나 작은 값의 영향을 받을 수 있지만, 중앙값은 이러한 이상치의 영향을 상대적으로 적게 받는다. 따라서 소요 시간이나 소득처럼 일부 값이 매우 크게 나타날 수 있는 데이터에서는 평균뿐만 아니라 중앙값을 함께 확인하는 것이 실제 데이터의 전형적인 수준을 파악하는 데 도움이 된다.
```

# 3단계 데이터 분석형 문제 🔍

## 문제 1. 과제 부담 해석하기

다트비 8기 신입 10명의 2주차 과제 소요 시간이 아래와 같았습니다.

```text
1, 1, 2, 2, 2, 3, 3, 4, 5, 12
```

1. 평균과 중앙값을 계산해 주세요. : 평균은 3.5 (시간), 중앙값은 2.5(시간) 
2. 운영진에게 과제 부담을 보고한다면 평균과 중앙값 중 어떤 값을 더 강조하고 싶나요? : 나는 중앙값 2.5시간을 조금 더 강조하되, 평균 3.5시간도 함께 제시할 것 같다.10명 중 대부분의 학생은 약 1~5시간 안에 과제를 완료했지만,한 명의 과제 소요 시간이 12시간으로 다른 학생들보다 매우 길다.평균은 이 12시간이라는 값의 영향을 받아 3.5시간까지 높아졌기 때문에 일반적인 학회원이 체감하는 과제 소요 시간을 나타내기에는 중앙값이 더 적절하다고 생각한다.다만 평균이 중앙값보다 1시간 높다는 사실 역시 일부 학회원에게 과제 부담이 매우 크게 나타났다는 신호일 수 있다.따라서 운영진에게 보고한다면 단순히 "보통 2.5시간 걸린다"고 결론내리기보다,중앙값은 2.5시간이지만 평균은 3.5시간이며,일부 학회원의 과제 소요 시간이 매우 길게 나타났다.라고 함께 설명하는 것이 데이터의 분포를 더 정확하게 전달할 수 있다고 생각한다.
3. 12시간이라는 값은 무조건 제거해야 할까요? 판단 기준을 적어 주세요. :12시간이라는 값이 다른 데이터보다 크다는 이유만으로 무조건 제거하면 안 된다.먼저 해당 값이 실제로 발생한 값인지 확인해야 한다.예를 들어 입력 과정에서 1.2시간을 12시간으로 잘못 입력한 것이라면 데이터 오류이므로 수정하거나 제외할 필요가 있다.하지만 실제로 한 학회원이 과제를 이해하거나 코드를 작성하는 데 12시간이 걸렸다면 이는 실제 관측값이며, 과제 난이도나 개인별 학습 격차를 보여주는 중요한 정보일 수도 있다. 따라서 이상치를 판단할 때는 1. 입력 또는 측정 오류인지 확인하고 2. 실제로 발생 가능한 값인지 확인하며 3. 해당 값을 포함했을 때 분석 결과가 얼마나 달라지는지 살펴본 뒤 제거 여부를 결정해야 한다.즉, 이상치는 '특이한 값'이지 곧바로 '잘못된 값'을 의미하는 것은 아니다.


# 4단계 오류 찾기 🚨

아래 문장을 읽고, 통계적으로 부적절한 부분을 고쳐 써 주세요.

> "평균 과제 소요 시간이 3.5시간이므로, 대부분의 학회원은 과제를 3-4시간 안에 끝냈다고 볼 수 있다."

```
수정한 문장과 그 이유를 작성해 주세요.
수정한 문장 : "평균 과제 소요 시간이 3.5시간이라는 사실만으로 대부분의 학회원이 과제를 3~4시간 안에 끝냈다고 판단할 수는 없다. 실제 과제 소요 시간이 어떻게 분포되어 있는지 확인하기 위해 중앙값이나 히스토그램 등 다른 요약 정보도 함께 살펴봐야 한다."
```
이유 : 평균은 데이터를 하나의 값으로 요약한 대푯값이지만, 각 데이터가 평균 주변에 얼마나 모여 있는지는 알려주지 않는다. 예를 들어 평균이 동일하게 3.5시간인 두 집단이라도 한 집단은 대부분의 학생이 실제로 3~4시간 정도 걸렸을 수 있고, 다른 집단은 일부 학생은 1시간, 일부 학생은 6시간 이상 걸렸을 수도 있다. 따라서 평균이 3.5시간이라는 사실만으로 "대부분의 사람이 3~4시간 안에 과제를 완료했다"고 해석하는 것은 적절하지 않다. 데이터를 올바르게 해석하려면 평균뿐만 아니라 중앙값, 데이터의 분포, 표준편차, 이상치 존재 여부 등을 함께 확인해야 한다.

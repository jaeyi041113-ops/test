## 01.

```
개념 이름:GROUP BY
개념 설명:특정 컬럼을 기준으로 같은 값끼리 모아서 그룹화 하는 것. 이때 타 컬럼들은 합이나 평균등으로 집계 가능함. 즉 기준점이 되는 컬럼을 정한다고 보면됨. 
-AVG : 평균
-COUNT : row 세기
-MAX : 최댓값
-MIN : 최솟값
-SUM : 합계
예시 쿼리:
SELECT type1, AVG(attack) as avg_attack, count(id) as cnt 
FROM poketmon
GROUP BY type1

```

## 02.

```
개념 이름:HAVING
개념 설명:WHERE , HAVING 모두 조건을 설정하고 싶을 때 사용함. WHERE 은 테이블에 바로 조건을 설정하고 싶은 경우. HAVING 은 GROUP BY 한 후 조건을 설정하고 싶은 경우에 사용함. WHERE 은 row 데이터가 대상이 되고 HAVING 은 그렇지 않음을 기억.
예시 쿼리:
SELECT 컬럼1, 컬럼2, COUNT(컬럼1) AS col1_count
FROM <table>
GROUP BY 컬럼1, 컬럼2
HAVING col1_count>3
```

## 🧩 문제 3

문제 링크: [고양이와 개는 몇 마리 있을까](https://school.programmers.co.kr/learn/courses/30/lessons/59040)

풀이 과정:

```
- 그룹화 기준: ANIMAL_TYPE
- WHERE와 HAVING 중 사용한 절: 둘 다 사용하지 않음
- 처음 틀렸다면 틀린 이유: COUNT(*)가 어떻게 동물 타입별 개수를 세는지 이해하지 못했다. COUNT(*) 자체가 동물 타입을 구분하는 것이 아니라, GROUP BY ANIMAL_TYPE으로 먼저 동물 타입별로 묶은 뒤 각 그룹의 행 개수를 센다는 점을 헷갈렸다.
- 새로 배운 SQL 패턴: GROUP BY로 특정 컬럼을 기준으로 데이터를 묶고, COUNT(*)를 사용해 각 그룹의 개수를 구하는 GROUP BY + COUNT(*) 패턴.
```

# 4️⃣ 이번 주 회고

```
1. 문제를 SQL로 옮길 때 가장 어려웠던 부분:COUNT(*)가 무엇을 기준으로 개수를 세는지 이해하는 것이 가장 어려웠다. 처음에는 COUNT(*)만 보고 어떻게 고양이와 개를 구분해서 세는지 궁금했는데, GROUP BY ANIMAL_TYPE으로 먼저 데이터를 동물 타입별로 묶고 COUNT(*)가 각 그룹에 속한 행의 수를 센다는 과정을 이해하게 되었다.
2. WHERE와 HAVING의 차이를 어떻게 이해했는지: WHERE는 그룹화하기 전에 필요한 데이터만 고르는 조건이고, HAVING은 GROUP BY로 그룹화한 후에 그룹에 조건을 거는 것으로 이해했다.
3. 다음 주에 더 연습하고 싶은 문제 유형:문제를 읽고 바로 함수가 주어지는 것이 아니라, 원하는 결과를 보고 어떤 컬럼을 기준으로 묶어야 하는지, 무엇을 세거나 비교해야 하는지를 직접 판단하는 문제를 더 연습하고 싶다. 생각보다 막상 문제를 받았을 때 두가지를 구분하는 것이 어려워서 조건이 여러 개 붙었을 때 WHERE와 HAVING 중 어느 단계에서 데이터를 걸러야 하는지 판단하는 문제를 풀어보고 싶다.
```

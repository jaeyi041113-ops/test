
## 02.

```
개념 이름: 문자열 함수 (CONCAT, REPLACE, TRIM)

개념 설명:
문자열 데이터를 합치거나, 일부를 바꾸거나, 불필요한 공백을 제거할 때 사용하는 함수이다.

CONCAT은 여러 문자열을 하나로 연결하고,
REPLACE는 문자열 안의 특정 값을 다른 값으로 바꾸며,
TRIM은 문자열 앞뒤의 불필요한 공백을 제거한다.
REPLACE 예시 : REPLACE(원래 문자열, 찾을 문자열, 바꿀 문자열)

데이터를 조회하는 것뿐만 아니라 분석하기 좋은 형태로 값을 정리할 때
문자열 함수가 필요하다는 점이 중요하다고 생각했다.

예시 쿼리:
SELECT
  CONCAT('SQL', '_BASIC') AS combined,
  REPLACE('SQL BASIC', 'BASIC', 'STUDY') AS replaced,
  TRIM('  SQL  ') AS trimmed;
  각각 SQL_BASIC / SQL STUDY / SQL 이 출력될 것. 
```

# 4️⃣ 이번 주 회고

```
1. 쿼리 작성 흐름을 잡을 때 도움이 된 방법:
문제의 조건을 한 번에 SQL로 옮기기보다 ‘무엇을 출력할지 → 어떤 데이터를 고를지 → 어떤 순서로 정렬할지’로 나누어 생각하는 것이 도움이 되었다. 특히 문자열 문제에서는 ‘포함’, ‘시작’, ‘앞 2자리’처럼 문제에 나온 표현을 먼저 찾으니 필요한 문법을 결정하기 쉬웠다.

2. 타입 변환이나 문자열 처리에서 조심해야 할 점:
문자열을 찾을 때는 %의 위치에 따라 조건의 의미가 달라진다는 점을 조심해야 한다. '%EL%'은 중간 어디에 있어도 찾지만, '강원도%'는 강원도로 시작하는 값만 찾는다. 또한 대소문자를 구분하지 않아야 하는 경우에는 UPPER()처럼 문자열을 같은 형태로 변환한 뒤 비교하는 방법도 확인해야 한다. 타입 변환에서는 CAST가 불가능한 값을 만나면 오류가 발생하지만 SAFE_CAST는 NULL을 반환한다는 차이를 기억해야 한다.

3. 앞으로 문제 풀이 때 먼저 확인할 것:
문제를 읽으면 먼저 원하는 결과 컬럼과 조건을 확인하고, 문자열 조건이라면 ‘포함인지, 시작인지, 일부를 추출해야 하는지’를 구분하려고 한다. 그다음 GROUP BY가 필요한지, 정렬 기준이 하나인지 여러 개인지까지 확인한 뒤 쿼리를 작성하는 습관을 들이고 싶다.
```

# 3️⃣ 확인 문제

## 🧩 문제 1

포켓몬 게임이나 이커머스 산업과 같이 다양한 산업에서는 각기 다른 데이터가 존재합니다. 다음 중 하나의 산업을 선택하고, 해당 산업에서 수집하고 활용될 수 있는 데이터 항목, 즉 컬럼 5가지를 자유롭게 상상하여 나열해주세요.

예시 산업:
- 온라인 음식 배달
- 스마트 헬스 케어
- 중고 거래 앱
- 교육 플랫폼

풀이 과정:

```
- 선택한 산업:온라인 음식 배달
- 떠올린 컬럼 5가지:user_id, 주문 메뉴, 주문 시간, 주문 금액, 배달 지역
- 해당 컬럼이 필요하다고 생각한 이유:user_id를 통해 어떤 사용자가 주문했는지 구분할 수 있고, 주문 메뉴를 통해 어떤 메뉴가 많이 판매되는지 확인할 수 있다. 주문 시간을 활용하면 사람들이 주로 언제 음식을 주문하는지 파악할 수 있고, 주문 금액을 통해 사용자별 평균 주문 금액이나 전체 매출 등을 확인할 수 있다. 배달 지역을 활용하면 지역별 주문량이나 인기 메뉴의 차이도 분석할 수 있을 것이라고 생각했다.
```

## 🧩 문제 2

이번 강의를 통해 SQL이 왜 필요하다고 느끼는지, SQL을 통해 본인이 어떤 것을 해내고 싶은지를 자유롭게 작성해주세요.

풀이 과정:

```
- SQL이 필요하다고 느낀 이유:실제 서비스에서는 많은 양의 데이터가 데이터베이스에 저장되기 때문에, 필요한 데이터를 직접 추출하고 분석하기 위해 SQL이 필요하다고 느꼈다. 특히 전체 데이터를 모두 확인하는 것이 아니라 분석 목적에 맞는 데이터만 골라서 가져올 수 있다는 점이 중요하다고 생각했다.

- SQL로 해보고 싶은 일:서비스의 사용자나 주문 데이터를 직접 추출해서 사용자들의 행동 패턴을 분석해보고 싶다. 예를 들어 어떤 시간대에 주문이 많이 발생하는지, 어떤 사용자가 자주 구매하는지 등을 SQL로 직접 확인해보고 싶다.

- 앞으로 SQL을 공부할 때 기대되는 점:지금은 데이터가 어떤 구조로 저장되는지를 배우는 단계지만, 앞으로 조건을 설정하거나 여러 데이터를 연결하는 방법을 배워서 원하는 데이터를 스스로 추출할 수 있게 되는 것이 기대된다.
```

## 01.

```
개념 이름: 표본오차 (Sampling Error)

개념 설명:
- 모집단 전체가 아닌 일부 '표본'으로 모집단을 추정하기 때문에 발생하는 오차
- 표본을 무작위로 잘 추출해도 표본마다 결과가 조금씩 달라질 수 있음
  → 표본평균 ≠ 모집단평균일 수 있음
- 즉, 조사나 계산을 잘못해서 생기는 오류가 아니라
  표본을 사용하는 과정에서 자연스럽게 발생하는 차이

[교재의 동전 던지기 예시]
모집단: 앞/뒤가 나올 확률 = 각각 1/2
→ 6번만 던지면 표본에 따라 앞면 비율이 1/2에서 벗어날 수 있음
→ 시행을 반복하면 이러한 오차는 확률적으로 발생

핵심:
표본의 결과 ≠ 모집단의 정확한 값
→ 표본을 이용하는 이상 어느 정도의 표본오차는 존재함

데이터 분석에서 중요한 이유:
표본에서 나온 하나의 결과를 모집단의 '정답'처럼 해석하지 않기 위해 필요하다.
표본 결과에는 우연한 차이가 포함될 수 있다는 점을 전제로 분석해야 한다.
```


## 02.

```
개념 이름: 표준오차 (Standard Error)

개념 설명:
- 여러 표본에서 나온 '표본평균들이 얼마나 흩어져 있는가'를 나타내는 값
- 쉽게 말하면 → 표본평균의 표준편차

표준오차(SE) = σ / √n
  σ : 모집단의 표준편차
  n : 표본 크기

[표본 크기와의 관계]
n ↑ → √n ↑ → 표준오차 ↓
→ 표본평균들이 모집단평균 주변에 더 가깝게 모임
→ 추정의 정밀도 ↑

※ 모집단의 표준편차 σ를 모르는 경우
→ 표본에서 구한 표준편차 s를 이용하여
   s / √n 으로 표준오차를 추정

핵심:
표준편차 = 개별 데이터가 얼마나 퍼져 있는가
표준오차 = 표본평균이 얼마나 흔들릴 수 있는가

데이터 분석에서 중요한 이유:
표본평균만으로는 그 값이 얼마나 안정적인 추정값인지 알기 어렵다.
표준오차를 함께 보면 표본평균의 변동 정도와 추정의 정밀성을 판단할 수 있다.
```


## 03.

```
개념 이름: 신뢰구간 (Confidence Interval)

개념 설명:
- 모집단의 값을 하나의 숫자로 추정하는 것이 아니라
  '어느 범위에 있을 것인가'로 추정하는 방법

점추정
→ 모집단평균을 하나의 값으로 추정

구간추정
→ 모집단평균을 일정한 범위로 추정
→ 이때 사용하는 범위가 '신뢰구간'

[95% 신뢰구간]
정규분포에서는 평균을 중심으로 약 95%가
±1.96 표준오차 범위에 위치

따라서 대략적으로
표본평균 ± 2 × 표준오차
를 이용해 95% 신뢰구간을 생각할 수 있음

※ 주의
"모집단평균이 이 구간에 있을 확률이 95%"라는 뜻 X

→ 같은 방법으로 표본추출을 반복하여 신뢰구간을 계속 만들었을 때
   만들어진 구간 중 약 95%가 실제 모집단평균을 포함한다는 의미

[신뢰구간의 크기]
표본 크기 n ↑
→ 표준오차 ↓
→ 신뢰구간 좁아짐
→ 추정의 정밀도 ↑

데이터 분석에서 중요한 이유:
평균 하나만 제시하는 것보다 추정값이 어느 정도 불확실한지까지 함께 보여줄 수 있다.
따라서 결과를 해석할 때 추정값의 신뢰성과 정밀도를 함께 판단할 수 있다.
```


# 2단계 확인 문제 ✅

## 문제 1. 신뢰구간 계산

8기 신입 16명을 조사했더니 평균 과제 소요 시간은 3.4시간, 표준오차는 0.3시간이었습니다.  
간단히 `평균 ± 2 × 표준오차`를 95% 신뢰구간의 근사값으로 사용한다고 합시다.

1. 95% 신뢰구간을 계산해 주세요.
3.4 ± 2 × 0.3 = 3.4 ± 0.6 이므로, 95% 신뢰구간은 2.8시간 ~ 4.0시간이다.
2. 이 신뢰구간을 한 문장으로 해석해 주세요.
같은 방법으로 표본을 반복해서 추출하고 신뢰구간을 계산한다면, 
그렇게 만들어진 구간 중 약 95%가 8기 전체의 실제 평균 과제 소요 시간을 포함한다고 해석할 수 있다.
3. 평균 3.4시간만 말하는 것보다 신뢰구간을 함께 말하는 것이 왜 더 좋은가요?
평균 3.4시간만 제시하면 모집단의 평균을 정확히 3.4시간으로 추정한 것처럼 보일 수 있다. 
하지만 표본을 이용한 추정에는 표본오차가 존재하므로,
2.8~4.0시간이라는 신뢰구간을 함께 제시하면 추정값이 가질 수 있는 불확실성의 정도까지 전달할 수 있다.


## 문제 2. 표본 크기와 대표성

다음 두 조사 중 어느 쪽이 더 적절한지 판단해 주세요.

| 조사 | 표본 구성 |
| --- | --- |
| A | 응답이 빠른 5명 |
| B | 8기 전체에서 무작위로 뽑은 15명 |

1. 일반적으로 어느 조사가 더 대표성이 높을 가능성이 있나요?
일반적으로 B 조사가 더 대표성이 높을 가능성이 있다. 
A는 응답이 빠른 5명만 조사했기 때문에 특정 성향의 사람이 표본에 포함될 가능성이 있다.
반면 B는 8기 전체에서 15명을 무작위로 추출했기 때문에
특정 집단에 치우칠 가능성이 상대적으로 낮고, 표본 크기도 더 크다.
2. 표본 크기가 커도 대표성이 낮을 수 있는 경우는 언제인가요?
표본 크기가 크더라도 특정 특성을 가진 사람들만 표본에 포함된다면 대표성이 낮을 수 있다.
예를 들어 8기 전체의 과제 소요 시간을 알고 싶은데
과제를 일찍 제출한 사람들만 대규모로 조사한다면,
표본 수가 많아도 전체 학회원의 특성을 제대로 반영한다고 보기 어렵다.
표본 크기는 표준오차와 추정의 정밀도에 영향을 주지만, 애초에 표본을 편향되게 뽑았다면 표본을 크게 만든다고 그 문제가 자동으로 해결되지는 않기 때문에 “큰 표본 = 무조건 좋은 표본”은 아니다.

## 문제 1. 결과 비교하기

두 팀이 8기 과제 소요 시간을 조사했습니다.

| 팀 | 표본평균 | 95% 신뢰구간 |
| --- | ---: | --- |
| A팀 | 3.1시간 | 2.2시간-4.0시간 |
| B팀 | 3.4시간 | 3.0시간-3.8시간 |

1. 어느 팀의 추정이 더 불확실해 보이나요?
A팀의 추정이 더 불확실해 보인다.
2. 그렇게 판단한 이유는 무엇인가요?
A팀의 95% 신뢰구간은 2.2~4.0시간으로 폭이 1.8시간이고,
B팀의 신뢰구간은 3.0~3.8시간으로 폭이 0.8시간이다.
신뢰수준이 동일하다면 신뢰구간이 넓을수록
모집단 평균을 추정할 수 있는 범위가 넓다는 의미이므로,
A팀의 추정이 상대적으로 더 불확실하다고 볼 수 있다.
3. 두 팀의 표본평균만 보고 B팀 조사 대상이 과제를 더 오래 했다고 단정할 수 있나요?
단정할 수 없다.
B팀의 표본평균 3.4시간이 A팀의 3.1시간보다 크기는 하지만,
두 값 모두 표본에서 얻은 추정값이고 각각 표본오차를 가지고 있다.
또한 두 팀의 신뢰구간도 서로 겹치기 때문에
표본평균의 차이만으로 실제 전체 집단에서도 차이가 있다고 결론 내리기는 어렵다.

## 문제 2. 보고 문장 작성하기

위 결과를 운영진에게 보고하는 문장을 2-3문장으로 작성해 주세요.

# 4단계 오류 찾기 🚨

아래 문장을 읽고, 통계적으로 부적절한 부분을 고쳐 써 주세요.

> "95% 신뢰구간이 2.8시간-4.0시간이므로, 8기 전체 평균이 이 구간 안에 있을 확률은 정확히 95%이다."

```
수정한 문장과 그 이유를 작성해 주세요.
```
수정한 문장 :
"95% 신뢰구간이 2.8시간~4.0시간이라는 것은,
같은 방법으로 표본을 반복해서 추출하고 신뢰구간을 계산했을 때
그렇게 만들어진 구간 중 약 95%가 8기 전체의 실제 평균을 포함한다는 의미이다."
이유 : 
이미 계산된 하나의 신뢰구간에 대해
'모집단 평균이 이 구간 안에 있을 확률이 95%'라고 해석하는 것은 적절하지 않다.
모집단 평균은 변하는 값이 아니라 이미 정해져 있는 값이고,
표본을 새로 뽑을 때마다 달라지는 것은 신뢰구간이다.
따라서 95%라는 수치는 현재 구간 안에 모집단 평균이 존재할 확률이라기보다,
동일한 방법으로 표본추출과 신뢰구간 계산을 반복했을 때
그 구간들이 실제 모집단 평균을 포함하는 비율을 의미한다.

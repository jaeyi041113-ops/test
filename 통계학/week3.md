## 01.

```
개념 이름: 정규분포
개념 설명:
- 평균을 중심으로 좌우가 대칭인 종 모양의 분포
- 평균 근처에 데이터가 많이 모이고, 평균에서 멀어질수록 적어진다.
- 분포의 중심은 평균, 퍼진 정도는 표준편차를 통해 확인할 수 있다.
- 같은 정규분포라도 평균과 표준편차에 따라 위치와 퍼진 정도가 달라진다.
데이터 분석에서 중요한 이유:
- 단순히 평균만 보는 것보다 데이터가 평균을 중심으로 어떻게 퍼져 있는지 함께 볼 수 있다.
- 특히 이후 표본평균의 분포를 이해할 때 정규분포가 중요하게 사용된다.
```


## 02.

```
개념 이름:표본분포
개념 설명:
- 같은 모집단에서도 어떤 표본을 뽑느냐에 따라 표본평균은 달라질 수 있다.
- 예를 들어 같은 모집단에서 5명씩 여러 번 뽑으면
  → 1번째 표본평균: 2.8
  → 2번째 표본평균: 3.1
  → 3번째 표본평균: 2.9
  처럼 매번 조금씩 다른 값이 나올 수 있다.
- 이렇게 반복해서 표본을 추출했을 때 얻어지는 통계량들의 분포가 표본분포이다.
데이터 분석에서 중요한 이유:
- 우리가 실제 분석에서 얻은 표본도 여러 가능한 표본 중 하나라는 점을 알 수 있다.
- 따라서 한 번 구한 표본평균을 바로 모집단의 평균이라고 생각하면 안 된다.
- 표본에서 나온 값이 어느 정도 흔들릴 수 있는지를 생각하게 해주는 개념이다.

```


## 03.

```
개념 이름:중심극한정리
개념 설명:
- 모집단의 분포가 정규분포가 아니더라도 표본의 크기가 충분히 커지면,
  표본평균의 분포는 정규분포에 가까워진다.
- 표본평균들은 모집단의 평균을 중심으로 모인다.
- 표본 크기가 커질수록 표본평균의 분포도 좁아져, 평균의 흔들림이 작아진다.
데이터 분석에서 중요한 이유:
- 모집단 전체를 직접 조사하지 않아도 표본을 이용해 모집단의 평균을 추론할 수 있는 근거가 된다.
- 특히 표본 크기가 커질수록 표본평균이 더 안정적으로 나타나는 이유를 이해할 수 있었다.
- 이후 배우는 신뢰구간과 같은 추론통계의 기초가 된다.
```


# 2단계 확인 문제 ✅

## 문제 1. 표본평균의 변동

다트비 8기 전체 25명의 실제 평균 과제 소요 시간이 3시간이라고 가정합니다.  
운영진이 매번 5명씩 무작위로 뽑아 평균 과제 소요 시간을 계산한다고 할 때, 다음 질문에 답해 주세요.

1. 매번 뽑은 5명의 평균은 항상 3시간일까요?
no. 모집단의 실제 평균이 3시간이더라도 어떤 5명이 표본으로 선택되는지에 따라 표본평균은 3시간보다 높거나 낮게 나올 수 있다. 표본을 무작위로 추출하는 과정에서 표본마다 포함되는 사람이 달라지기 때문이다.
2. 표본을 여러 번 뽑으면 표본평균들은 어떤 값 주변에 모일 가능성이 높나요?
표본평균들은 모집단의 실제 평균인 3시간 주변에 모일 가능성이 높다. 각각의 표본평균에는 차이가 있을 수 있지만, 반복해서 표본을 추출했을 때 표본평균의 분포는 모집단의 평균을 중심으로 형성된다.
3. 표본 크기를 5명에서 15명으로 늘리면 표본평균의 흔들림은 일반적으로 어떻게 달라질까요?
표본 크기가 커질수록 표본평균의 흔들림은 일반적으로 작아진다. 적은 수의 사람을 조사할 때보다 많은 사람을 조사할수록 특정 개인의 값이 평균에 미치는 영향이 줄어들기 때문에 표본평균이 비교적 안정적으로 나타난다.


## 문제 2. 정규분포 감각

어떤 시험 점수가 평균 70점, 표준편차 10점인 정규분포를 따른다고 가정합니다.

1. 80점은 평균보다 몇 표준편차 위에 있나요? 
1표준편차 위
평균은 70점이고, 80점은 평균보다 10점 높음
표준편차가 10점이므로 → 1표준편차 위
2. 50점은 평균보다 몇 표준편차 아래에 있나요?
2표준편차 아래
평균은 70점이고, 50점은 평균보다 20점 낮음
표준편차가 10점이므로 → 2표준편차 아래
3. 50점과 80점 중 평균에서 더 멀리 떨어진 값은 무엇인가요?
50점이다. 50은 2표준편차 80은 1표준편차만큼 떨어져있기 때문이다. 단순히 점수 차이를 보는 것뿐 아니라, 평균으로부터 표준편차 몇 개만큼 떨어져 있는지를 통해 각 값의 상대적인 위치를 확인할 수 있다.


# 3단계 데이터 분석형 문제 🔍

## 문제 1. 표본 결과 비교하기

운영진이 8기 신입의 과제 소요 시간을 파악하기 위해 표본을 두 번 뽑았습니다.

| 조사 | 표본 크기 | 표본평균 |
| --- | ---: | ---: |
| 1차 조사 | 5명 | 2.4시간 |
| 2차 조사 | 15명 | 3.1시간 |

1. 두 표본평균이 다른 이유는 무엇일 수 있나요?
표본의 크기가 다르고, 두 조사에서 뽑힌 사람이 서로 다르기 때문이다. 같은 모집단에서 표본을 추출하더라도 어떤 사람이 포함되는지에 따라 표본평균은 달라질 수 있다. 따라서 2.4시간과 3.1시간의 차이가 반드시 모집단 자체가 변했다는 의미는 아니며, 표본추출 과정에서 발생하는 변동일 수 있다.
2. 둘 중 어느 조사 결과가 일반적으로 더 안정적이라고 볼 수 있나요?
표본읭 크기가 15명인 2차 조사가 일반적으로 더 안정적이라고 볼 수 있다. 표본의 크기가 커질수록 특정한 몇 명의 값이 전체 평균에 미치는 영향이 줄어들고 표본평균의 변동도 작아지는 경향이 있기 때문이다.
3. 그래도 2차 조사 결과를 8기 전체의 정확한 평균이라고 단정할 수 없는 이유는 무엇인가요?
2차 조사 역시 8기 전체의 모수를 알 수가 없고 15명이라는 하나의 표본을 조사한 결과이기 때문이다. 다른 15명을 다시 뽑으면 표본평균이 3.1시간과 다르게 나올 수 있으므로, 3.1시간은 모집단의 평균을 추정하기 위한 값이지 모집단의 정확한 평균이라고 단정할 수는 없다.


## 문제 2. 해석 문장 작성하기

위 조사 결과를 바탕으로 운영진에게 전달할 문장을 2-3문장으로 작성해 주세요.
2차 조사에서 15명의 평균 과제 소요 시간은 3.1시간으로 나타났으며, 5명을 조사한 1차 조사보다 표본 크기가 커 상대적으로 안정적인 결과로 볼 수 있다. 다만 표본을 다시 추출하면 평균이 달라질 수 있으므로, 3.1시간을 8기 전체의 정확한 평균이라기보다는 전체 평균을 추정하기 위한 값으로 해석하는 것이 적절하다.

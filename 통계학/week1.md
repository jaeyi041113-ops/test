# 1단계 개념 정리 ✍️

이번 주 교재 범위에서 본인이 중요하다고 생각한 개념 3개를 골라 정리해 주세요.

## 01.

```
개념 이름:모집단
개념 설명:모집단은 데이터 분석을 통해 특성을 알고자 하는 전체 대상을 의미한다. 같은 데이터를 분석하더라도 분석 목적에 따라 알고자 하는 대상이 달라질 수 있기 때문에, 먼저 분석 목적을 구체화하고 그에 맞는 모집단을 설정해야 한다. 
데이터 분석에서 중요한 이유:모집단을 어떻게 설정하느냐에 따라 분석 결과를 해석하고 적용할 수 있는 범위가 달라진다. 따라서 실제 데이터를 분석하기 전에 '이 분석을 통해 궁극적으로 누구에 대해 알고 싶은가'를 명확히 하는 것이 중요하다. 
```


## 02.

```
개념 이름:표본
개념 설명:표본은 모집단의 특성을 알아보기 위해 모집단에서 실제로 추출하여 조사하는 일부 대상을 의미한다. 현실에서는 시간과 비용의 한계나 모집단의 크기 때문에 전수조사가 어려운 경우가 많아, 일부 표본을 조사한 뒤 그 결과를 바탕으로 모집단의 성질을 추정한다. 
데이터 분석에서 중요한 이유:우리가 실제 가지고 있는 데이터가 모집단 전체가 아니라 표본일 경우, 표본에서 나타난 결과가 곧바로 모집단 전체의 결과를 의미하는 것은 아니다. 따라서 분석할 때는 현재 가진 데이터가 누구에게서 수집된 표본인지 파악하고, 그 결과를 모집단까지 일반화할 수 있는지를 함께 고려해야 한다. 
```


## 03.

```
개념 이름:대표성
개념 설명:대표성은 조사한 표본이 모집단의 특성을 얼마나 적절하게 반영하고 있는지를 의미한다. 표본의 크기가 크더라도 특정 특성을 가진 대상이 지나치게 많이 포함되는 등 표본이 한쪽으로 치우쳐 있다면 모집단의 실제 특성과 다른 결과가 나타날 수 있다. 
데이터 분석에서 중요한 이유:표본조사의 목적은 표본 자체만 설명하는 것이 아니라, 표본을 통해 모집단의 성질을 추정하는 데 있다. 따라서 표본의 수를 단순히 늘리는 것뿐 아니라 모집단의 다양한 특성이 표본에 적절히 반영되도록 표본을 추출하는 것이 중요하다. 
```

## 문제 1. 설문 결과 해석하기

다트비 운영진은 8기 신입 25명의 통계학 사전 지식을 파악하려고 합니다.  
먼저 응답이 빠른 8명에게 설문을 받았고, 결과는 아래와 같았습니다.

| 응답자 그룹 | 응답자 수 | "통계학을 배운 적 있다" 응답자 수 |
| --- | ---: | ---: |
| 응답이 빠른 8기 신입 | 8명 | 5명 |

다음 질문에 답해 주세요.

1. 이 표본에서 통계학을 배운 적 있는 비율은 얼마인가요? : 62.5%
2. 이 결과만으로 8기 전체의 통계학 사전 지식이 충분하다고 말하기 어려운 이유는 무엇인가요? : 조사한 8기 8명은 신입 25명 중 일부일 뿐이고, 특히 '응답이 빠른 사람'만을 대상으로 했기 때문에 이 표본이 8기 전체의 특성을 잘 대표한다고 보기 어렵다. 따라서 8명의 결과만으로 8기 전체의 통계학 사전 지식을 파악하는데에는 한계가 있다. 
3. 8기 전체를 더 잘 파악하려면 표본을 어떻게 모으는 것이 좋을까요? : 가능하다면 25명 전체를 조사하는 것이 좋고, 응답이 빠른 사람만 조사할것이 아니라 8기 신입 전체에서 특정 특성에 치우치지 않도록 표본을 추출하는 것이 좋다.

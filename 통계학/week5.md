## 01.

```
개념 이름: 귀무가설과 대립가설

개념 설명:
- 가설검정에서는 서로 반대되는 두 가지 가설을 설정하고 데이터를 통해 판단함

귀무가설(H0)
→ 검정에서 '기각하고 싶은 가설'
→ 일반적으로 차이 또는 효과가 없다고 가정
→ 예: "새 과제와 기존 과제의 평균 만족도에는 차이가 없다."

대립가설(H1)
→ 귀무가설과 반대되는 가설
→ 연구자가 데이터로 확인하고 싶은 차이나 효과가 존재한다는 가설
→ 예: "새 과제의 평균 만족도가 기존 과제보다 높다."

[가설검정의 기본 흐름]
귀무가설이 옳다고 가정
→ 그 가정 아래에서 현재와 같은 데이터가 얼마나 나타나기 어려운지 확인
→ 충분히 드문 결과라면 귀무가설을 기각하고 대립가설을 선택

※ 주의
귀무가설을 기각하지 못했다고 해서
→ 귀무가설이 옳다는 것을 증명한 것은 아님
→ 현재 데이터만으로 귀무가설을 기각할 충분한 근거를 찾지 못했다는 의미

데이터 분석에서 중요한 이유:
표본에서 관찰된 차이가 단순한 우연인지, 실제 집단에서도 차이가 있다고 판단할 만한 근거가 있는지를 확인하는 출발점이 된다.
```

## 02.

```
개념 이름: p값 (p-value)

개념 설명:
- 귀무가설이 옳다고 가정했을 때,
  현실에서 관찰한 결과와 같거나 그보다 더 극단적인 결과가 나타날 확률

[해석]
p값이 작음
→ 귀무가설이 옳은 세계에서는 현재와 같은 결과가 나타나기 드물다는 뜻
→ 귀무가설을 의심할 근거가 커짐

p값이 큼
→ 현재와 같은 결과가 귀무가설 아래에서도 충분히 나타날 수 있음
→ 귀무가설을 기각할 충분한 근거가 없음

[유의수준과 비교]
보통 유의수준 α = 0.05 사용

p < 0.05
→ 귀무가설 기각
→ "통계적으로 유의한 차이가 있다"고 판단

p ≥ 0.05
→ 귀무가설을 기각하지 않음
→ "통계적으로 유의한 차이를 발견하지 못했다"고 판단

※ 주의
p값이 작다고 해서
→ 효과의 크기가 크다는 뜻 X
→ 대립가설이 옳을 확률을 의미하는 것 X
→ 결과가 실질적으로 중요하다는 뜻 X

데이터 분석에서 중요한 이유:
표본에서 관찰된 차이가 우연만으로 나타났다고 보기 어려운지를 판단하는 기준이 된다.
다만 p값만으로 효과의 크기나 실제 중요성까지 판단할 수 없기 때문에 효과크기나 신뢰구간 등과 함께 해석해야 한다.
```

## 03.

```
개념 이름: 제1종 오류와 제2종 오류

개념 설명:
가설검정의 판단과 실제 상황이 다르면 오류가 발생할 수 있음.

[제1종 오류]
실제로는 귀무가설이 옳은데 귀무가설을 기각하는 오류
→ 실제로 차이가 없는데 "차이가 있다"고 판단
→ false positive

제1종 오류가 발생할 확률 = α
→ 유의수준을 α = 0.05로 설정했다면
   제1종 오류를 허용할 확률을 5%로 설정한 것

[제2종 오류]
실제로는 대립가설이 옳은데 귀무가설을 기각하지 못하는 오류
→ 실제로 차이가 있는데 "차이를 발견하지 못했다"고 판단
→ false negative

제2종 오류가 발생할 확률 = β

[두 오류의 관계]
α를 작게 설정
→ 제1종 오류의 가능성은 감소
→ 하지만 조건이 같다면 제2종 오류 β는 증가할 수 있음

표본 크기 n ↑
→ 검정의 정확도가 높아져 제2종 오류를 줄이는 데 도움이 됨

데이터 분석에서 중요한 이유:
가설검정의 결과가 항상 실제 상황과 일치하는 것은 아니므로,
'유의하다/유의하지 않다'라는 결론에도 잘못된 판단의 가능성이 있다는 점을 고려해야 한다.
어떤 오류를 더 중요하게 피해야 하는지도 분석 상황에 따라 달라질 수 있다.
```


# 2단계 확인 문제 ✅

## 문제 1. 가설 세우기

운영진은 새로 바꾼 통계학 과제가 기존 과제보다 만족도가 높은지 확인하고 싶습니다.

1. 귀무가설을 적어 주세요.

귀무가설(H0): 새 과제의 평균 만족도는 기존 과제보다 높지 않다.

즉, 새 과제로 변경하더라도 기존 과제와 비교해 만족도가 높아지는 효과는 없다고 가정한다.

2. 대립가설을 적어 주세요.

대립가설(H1): 새 과제의 평균 만족도는 기존 과제보다 높다.

즉, 새 과제로 변경한 뒤 평균 만족도가 실제로 증가했다고 보는 가설이다.

3. 이 검정에서 비교하고 싶은 값은 무엇인가요?

기존 과제의 평균 만족도와 새 과제의 평균 만족도를 비교하고 싶다.
구체적으로는 두 집단의 모집단 평균 만족도 차이가 0보다 큰지를 확인하는 것이다.


## 문제 2. p값 해석

가설검정 결과 p값이 0.04였습니다.

1. 유의수준 5%에서는 귀무가설을 기각할 수 있나요?

기각할 수 있다.

p = 0.04 < α = 0.05이므로,
귀무가설이 옳다고 가정했을 때 현재와 같거나 더 극단적인 결과가 나타날 확률이 4%라는 의미이다.

이는 미리 정한 유의수준 5%보다 작으므로 귀무가설을 기각하고,
새 과제의 평균 만족도가 기존 과제보다 높다는 통계적 근거가 있다고 판단할 수 있다.

2. p값이 0.04라는 사실만으로 새 과제가 실질적으로 매우 좋다고 말할 수 있나요?

말할 수 없다.

p값은 관찰된 차이가 귀무가설 아래에서 얼마나 드문지를 나타낼 뿐,
차이의 크기 자체를 나타내는 값은 아니다.

따라서 p = 0.04라는 결과만으로
새 과제가 기존 과제보다 '훨씬 좋다'거나 실제 만족도 개선 효과가 크다고 판단할 수는 없다.

3. p값 외에 함께 확인하면 좋은 정보는 무엇인가요?

두 과제의 실제 평균 만족도 차이와 효과크기, 신뢰구간 등을 함께 확인하면 좋다.

p값으로 통계적으로 유의한 차이가 있는지를 판단하고,
효과크기와 실제 평균 차이를 통해 그 차이가 실질적으로 얼마나 큰지를 확인할 수 있다.
또한 신뢰구간을 함께 보면 추정된 차이가 어느 정도의 불확실성을 가지는지도 확인할 수 있다.


# 3단계 데이터 분석형 문제 🔍

## 문제 1. 과제 개편 효과 판단하기

기존 과제 만족도 평균은 3.6점, 새 과제 만족도 평균은 3.9점이었습니다.  
두 조사 모두 표본 크기는 20명이고, 가설검정 결과 p값은 0.04였습니다.

1. 평균 만족도 차이는 몇 점인가요?

3.9 - 3.6 = 0.3점이므로,
새 과제의 표본평균 만족도가 기존 과제보다 0.3점 높다.

2. 통계적으로 어떤 결론을 내릴 수 있나요?

p = 0.04로 일반적인 유의수준 α = 0.05보다 작으므로 귀무가설을 기각할 수 있다.

따라서 표본에서 나타난 0.3점의 차이가 단순한 우연만으로 나타났다고 보기 어렵고,
새 과제의 만족도가 기존 과제보다 높다는 통계적인 근거가 있다고 판단할 수 있다.

다만 이것이 새 과제가 기존 과제보다 '훨씬 좋다'는 의미는 아니다.
통계적으로 유의한 차이가 있다는 것과 그 차이가 실질적으로 큰 것은 구분해야 한다.

3. 다음 기수에도 새 과제를 적용할지 결정하려면 어떤 정보를 더 확인해야 하나요?

0.3점이라는 차이가 실제 운영에서도 의미 있는 수준인지 확인하기 위해
효과크기와 평균 차이의 신뢰구간을 함께 확인할 필요가 있다.

또한 이번 조사의 표본이 전체 학회원을 잘 대표하는지,
새 과제의 난이도나 과제 소요 시간 등 만족도 이외의 변화는 없었는지도 확인해야 한다.

즉, p값 하나만으로 다음 기수 적용 여부를 결정하기보다
'통계적으로 차이가 있는가'와 '그 차이가 실제로도 의미가 있는가'를 함께 판단해야 한다.


## 문제 2. 오류의 종류 구분

아래 상황이 `1종 오류`인지 `2종 오류`인지 구분해 주세요.

1. 실제로는 새 과제가 기존 과제와 별 차이가 없는데, 차이가 있다고 결론 내렸다.

→ 제1종 오류

실제로는 귀무가설이 옳은 상황인데 귀무가설을 기각한 경우이다.
즉, 실제로 효과가 없는데 효과가 있다고 잘못 판단한 것이다.


2. 실제로는 새 과제가 기존 과제보다 만족도가 높은데, 차이가 없다고 결론 내렸다.

→ 제2종 오류

실제로는 대립가설이 옳아 차이가 존재하지만,
귀무가설을 기각하지 못한 경우이다.
즉, 실제로 존재하는 효과를 발견하지 못한 것이다.


# 4단계 오류 찾기 🚨

아래 문장을 읽고, 통계적으로 부적절한 부분을 고쳐 써 주세요.

```
수정한 문장과 그 이유를 작성해 주세요.
```

수정한 문장 :

"가설검정 결과 p값이 0.04로 유의수준 0.05보다 작으므로,
새 과제의 만족도가 기존 과제보다 높다는 통계적으로 유의한 근거가 있다고 볼 수 있다.
다만 p값만으로 만족도 차이가 실질적으로 큰지 판단할 수 없으므로,
효과크기와 신뢰구간, 실제 평균 차이 등을 추가로 확인한 뒤 다음 기수 적용 여부를 결정해야 한다."


이유 :

p값이 0.04라는 것은 귀무가설이 옳다고 가정했을 때,
현재 관찰한 결과와 같거나 그보다 더 극단적인 결과가 나타날 확률이 4%라는 의미이다.

따라서 p값이 0.05보다 작다는 것은 귀무가설을 기각할 통계적 근거가 된다는 의미이지,
새 과제가 '훨씬 좋다'는 사실 자체를 증명하는 것은 아니다.

특히 p값은 효과의 크기를 나타내지 않기 때문에,
통계적으로 유의한 결과가 실제로도 큰 차이 또는 중요한 차이라는 의미는 아니다.

따라서 다음 기수 적용 여부와 같은 실제 의사결정에서는
p값뿐만 아니라 평균 차이, 효과크기, 신뢰구간과 실제 운영상의 의미 등을 함께 고려해야 한다.

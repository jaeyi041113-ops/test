## 01.

```
개념 이름:상관관계
개념 설명:상관관계는 두 양적 변수가 함께 변화하는 방향과 강도를 나타내는 관계이다. 이를 수치화한 것이 **상관계수(r)**이며, -1부터 +1 사이의 값을 가진다.
- 양의 상관관계(r > 0): 한 변수가 증가할 때 다른 변수도 증가하는 경향
- 음의 상관관계(r < 0): 한 변수가 증가할 때 다른 변수는 감소하는 경향
- 상관계수의 절댓값: 1에 가까울수록 선형관계가 강하고, 0에 가까울수록 약함
상관계수는 선형관계를 나타내므로 산점도를 함께 확인해야 하며, 상관관계가 존재한다고 해서 인과관계가 성립하는 것은 아니다.
데이터 분석에서 중요한 이유:변수 사이의 관계를 파악하고 추가 분석이 필요한 변수를 탐색하는 데 활용된다. 다만 제3의 변수나 이상치의 영향을 받을 수 있으므로, 상관계수만으로 원인과 결과를 판단하지 않는 것이 중요하다.
```


## 02.

```
개념 이름:단순선형회귀
개념 설명:단순선형회귀는 하나의 독립변수(X)를 이용해 종속변수(Y)의 값을 설명하거나 예측하는 분석 방법이다.
\[
\hat{Y}=b_0+b_1X
\]

- 절편(b₀): X가 0일 때 예측되는 Y의 값
- 회귀계수(b₁): X가 1단위 증가할 때 Y의 예측값이 변화하는 정도
- 잔차: 실제 관측값과 예측값의 차이
- 결정계수(R²): 종속변수의 변동 중 회귀모형이 설명하는 비율
회귀분석은 변수 간 관계를 수식으로 표현하지만, 회귀계수만으로 인과관계를 증명할 수는 없다.
데이터 분석에서 중요한 이유:독립변수의 변화에 따른 종속변수의 예측값을 구하고, 회귀계수와 결정계수를 통해 관계의 방향·크기와 모형의 설명력을 평가할 수 있다.
```


# 2단계 확인 문제 ✅

## 문제 1. 상관관계 해석

학술제 준비 시간과 프로젝트 완성도 점수의 상관계수가 0.62로 나왔다고 합시다.

1. 상관계수 0.62는 어떤 관계를 의미하나요?
학술제 준비 시간과 프로젝트 완성도 점수 사이에 비교적 뚜렷한 양의 선형관계가 있음을 의미한다. 즉, 준비 시간이 긴 팀일수록 완성도 점수가 높은 경향이 있다는 뜻이다.
2. 이 결과만으로 "준비 시간이 길어지면 반드시 완성도가 높아진다"고 말할 수 있나요?
말할 수 없다. 상관관계는 두 변수의 연관성을 나타낼 뿐 인과관계를 증명하지 않기 때문이다. 프로젝트 완성도에는 준비 시간 외에도 팀원의 역량, 협업 효율성 등 다양한 요인이 영향을 미칠 수 있다.


# 3단계 데이터 분석형 문제 🔍

## 문제 1. 회귀 결과 읽기

다음은 단순회귀분석 결과입니다.

```text
프로젝트 완성도 점수 = 60 + 3.5 * 주간 회의 시간
R² = 0.40
```

1. 회귀계수 3.5는 어떻게 해석할 수 있나요?
주간 회의 시간이 1시간 증가할 때 프로젝트 완성도 점수의 예측값이 평균적으로 3.5점 높아진다는 의미이다. 단, 회의 시간을 늘리는 것이 실제 점수 상승을 유발한다는 뜻은 아니다.
2. R² = 0.40은 무엇을 의미하나요?
프로젝트 완성도 점수의 전체 변동 중 40%를 주간 회의 시간을 이용한 회귀모형이 설명한다는 의미이다. 나머지 60%는 해당 모형으로 설명되지 않는 변동이다.
3. 위 결과를 바탕으로 운영진에게 전달할 문장을 2문장으로 작성해 주세요.
주간 회의 시간이 1시간 증가할 때 프로젝트 완성도 점수의 예측값은 평균 3.5점 높아지는 경향이 있으며, 회귀모형의 설명력은 40%로 나타났습니다. 다만 회의 시간과 완성도 사이의 인과관계가 입증된 것은 아니므로, 협업 효율성과 회의의 질 등 다른 요인도 함께 고려할 필요가 있습니다.

# 4단계 오류 찾기 🚨

아래 문장을 읽고, 통계적으로 부적절한 부분을 고쳐 써 주세요.

> "학술제 준비 시간과 완성도 점수의 상관계수가 양수이므로, 준비 시간을 늘리면 모든 팀의 완성도는 반드시 높아진다."

```
수정한 문장과 그 이유를 작성해 주세요.
```
수정한 문장:

학술제 준비 시간과 프로젝트 완성도 점수 사이에 양의 상관관계가 나타났으므로, 준비 시간이 긴 팀일수록 완성도 점수가 높은 경향이 있다고 해석할 수 있다. 그러나 준비 시간을 늘린다고 해서 모든 팀의 완성도가 반드시 높아지는 것은 아니다.

수정한 이유:

기존 문장은 상관관계를 인과관계로 혼동하고, 전체 데이터에서 나타난 경향을 모든 팀에 일반화했다는 문제가 있다. 양의 상관관계는 두 변수가 함께 증가하는 경향을 의미할 뿐이며, 다른 영향 요인을 통제하지 않은 상태에서 준비 시간 증가가 완성도 향상의 직접적인 원인이라고 단정할 수 없다.
